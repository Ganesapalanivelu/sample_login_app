# Login Test Cases

| TC ID | Test Scenario | Test Steps | Expected Result |
|---|---|---|---|
| TC001 | Verify login page | Open login page | Login page should be displayed |
| TC002 | Login with valid credentials | Enter valid username/password and click Login | User should login successfully |
| TC003 | Login with invalid username | Enter invalid username and valid password | Error message should be displayed |
| TC004 | Login with invalid password | Enter valid username and invalid password | Error message should be displayed |
| TC005 | Login with empty username | Leave username empty and enter password | Validation message should appear |
| TC006 | Login with empty password | Enter username and leave password empty | Validation message should appear |
| TC007 | Verify password masking | Enter password | Password should be masked |
