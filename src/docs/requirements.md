# Login Application Requirements

## Login

1. User should be able to enter username.
2. User should be able to enter password.
3. User should be able to click Login.
4. Username is mandatory.
5. Password is mandatory.
6. Password should be masked.
7. Valid username and password should allow login.
8. Invalid username/password should display an error message.
9. User should not be able to login with empty credentials.
10. Login button should be visible and clickable.
